# Bitcoin Timechain Widgets

An Android widget app displaying Bitcoin timechain status and statistics for Bitcoiners.

[![Min SDK](https://img.shields.io/badge/Android-8.0%2B-brightgreen)](https://developer.android.com/about/versions/oreo)
[![Material 3](https://img.shields.io/badge/Material-3-blue)](https://m3.material.io/)

---

## Features

- Dark theme support (Android 10+)
- Material 3 design system with Dynamic Colors (Android 12+)
- Auto-updates data every 15 minutes
- Manual refresh by tapping any widget
- Resizable widgets
- Edge-to-edge support (Android 15+)

---

## Widgets

| Widget | Size | Description |
|--------|------|-------------|
| Block Height | 2×1 | Current Bitcoin block height |
| Transaction Fees | 3×1 | High, medium, and low priority fees |
| Fee Priority | 3×1 | Recommended fee display |
| Supply | 2×1 | Circulating BTC supply |
| Market Cap | 2×1 | Bitcoin market capitalization |
| Hash Rate | 2×1 | Current network hash rate |
| Halving Progress | 2×1 | Progress through current halving cycle |
| Blocks to Next Halving | 2×1 | Remaining blocks until next halving |
| Days Until Next Halving | 2×1 | Estimated days until next halving |
| Next Halving Date | 2×1 | Estimated date of next halving |
| Moscow Time | 2×1 | Satoshis per US dollar |
| Siam Time | 2×1 | Satoshis per Thai Baht |
| Total Nodes | 2×1 | Reachable Bitcoin nodes worldwide |
| Bitcoin Quote | 4×2 | Random Bitcoin quote |
| Dashboard | 4×2 | Block height, fees, hash rate, Moscow time, and halving info |

## How to Use

1. Long-press your home screen
2. Select **Widgets**
3. Find **Bitcoin Timechain Widgets** and drag to your home screen

---

## Data Providers

- [CoinGecko](https://www.coingecko.com/) — Price and market cap
- [Bitnodes](https://bitnodes.io/) — Node count
